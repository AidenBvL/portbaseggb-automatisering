GGB-assistent – AI-instellingen

Voor AI invullen gebruikt de extensie Claude van Anthropic. Je hebt een eigen API-sleutel nodig (console.anthropic.com → API keys).

Wordt alleen lokaal in deze browser bewaard (chrome.storage.local) en alleen naar api.anthropic.com gestuurd.

Privacy: bij Uitlezen met AI worden de geselecteerde documenten (HC, factuur, enz.) naar de API van Anthropic gestuurd. Er wordt niets verstuurd zolang je die knop niet gebruikt. Controleer of dit past binnen de afspraken van je organisatie.
